# Verbos Ingles 1

## Pronombre

| Persona | Inglés | Pronunciación |
|---|---|---|
| 1ª Persona Singular | I | ái |
| 2ª Persona Singular | You | iu |
| 3ª Persona Singular | He / She / It | ji / shi / it |
| 1ª Persona Plural | We | ui |
| 2ª Persona Plural | You | iu |
| 3ª Persona Plural | They | dei |


## Verbos básicos en presente

- **To be**:  Ser / Estar
- **To have got**:  Tener

### To be - Presente (positivo)

| Inglés | Pronunciación |
|---|---|
| I am / I'm | ái am / áim |
| You are / You're | iu ar / iór |
| He is / He's | ji is / jis |
| She is / She's | shi is / shis |
| It is / It's | it is / its |
| We are / We're | ui ar / uíar |
| You are / You're | iu ar / iór |
| They are / They're | dei ar / déir |

En inglés britanico la **R final es muy suave, casi no se pronuncia**.  Pero para un castellano parlante es útil escribirla para no olvidar que está ahí.


### To be - Presente (negativo)

| Inglés | Pronunciación |
|---|---|
| I am not / I'm not | ái am not / áim not |
| You are not / You're not / You aren't | iu ar not / iór not / iu árent |
| He is not / He's not / He isn't | ji is not / jis not / ji ísent |
| She is not / She's not / She isn't | shi is not / shis not / shi ísent |
| It is not / It's not / It isn't | it is not / its not / it ísent |
| We are not / We're not / We aren't | ui ar not / uíar not / ui árent |
| You are not / You're not / You aren't | iu ar not / iór not / iu árent |
| They are not / They're not / They aren't | dei ar not / déir not / dei árent |

Nota

    - La r final en UK es muy suave, casi no se pronuncia, pero la escribo para que no se olvide.

    - aren't → suena árent (con e corta, no a).

    - isn't → suena ísent (con e débil).
