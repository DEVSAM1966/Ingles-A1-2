=== PÁGINA 10 ===
GRAMÁTICA INGLÉS I
Es el equivalente de EVERYTHING = todo.
• SOMEONE / SOMEBODY  →  “alguien” / “una persona”  →  
( som-uon / som-bodi )
SOMEONE y SOMEBODY son intercambiables.
En inglés moderno, SOMEONE suena un poco más formal, pero en la práctica se usan 
igual.
• SOMEWHERE  →  “en algún lugar” / “en alguna parte”  →  
( som-wer )
Se usa cuando no sabes el lugar exacto, pero sabes que existe un lugar.
• SOMETHING  →  “algo” / “alguna cosa”  →  
( som-zin )
Se usa cuando existe una cosa, pero no sabes cuál o no quieres especificarla.
• ANYONE / ANYBODY  →  “cualquiera” / “alguien” (en preguntas o negativas)  →
( éni-uon / éni-bodi )
Se usan cuando no sabes quién, o cuando no hay nadie.
ANYONE y ANYBODY son intercambiables.
En inglés moderno, ANYONE suena un poco más formal, pero en la práctica se usan igual.
• ANYWHERE  →  “en cualquier lugar” / “donde sea” / “en ningún lugar” (en
negativas)  → 
( éni-wer )
En preguntas: “en algún lugar / en cualquier lugar”.
En negativas: “en ningún lugar”.
En afirmativas: “en cualquier lugar”.
• ANYTHING  →  “cualquier cosa” / “algo” / “nada” (en negativas)  → 
( éni-zin )
En preguntas: “algo / cualquier cosa”.
En negativas: “nada”.
En afirmativas: “cualquier cosa”.
• NO ONE / NOBODY  →  “nadie” / “ninguna persona”  →
( nóu-uon / nóu-bodi )
NO ONE y NOBODY son intercambiables.

=== PÁGINA 11 ===
GRAMÁTICA INGLÉS I
NO ONE suena un poco más formal, pero en la práctica se usan igual.
• NOWHERE  →  “en ninguna parte” / “en ningún lugar”  → 
( nóu-wer ) 
Se usa para indicar ausencia total de lugar.
Es el contrario de somewhere y anywhere.

Pronombres indefinidos – Oraciones afirmativas.
En oraciones afirmativas, los pronombres indefinidos con  “SOME” se usan para describir una
cantidad indefinida.
Con “EVERY” se usan para describir una cantidad completa y los que llevan no implican ausencia
de cantidad.
Los pronombres con “ NO” se usan a menudo en oraciones afirmativas con sentido negativos, no
son oraciones negativas ya que les faltan la palabra “NOT”.
Ejemplos:
• Everyone   is sleeping in mi bed I gave everything to Sally.
évri-uon is slípin in mai bed ai geiv évri-zin tu Sáli
